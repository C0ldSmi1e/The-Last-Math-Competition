# TLMC 00000003829 counterexample

At `(s,t) = (2,3)`, the full simultaneous-core vertex set is exactly the empty partition and the one-cell partition. A one-cell border joins them. The component quotient therefore has exactly one element, while the claimed rational Catalan value is `binom(5,2)/5 = 10/5 = 2`.

## Semantic scope

The official statement says that edges are generated by adding and removing “borders” without specifying a length restriction. This project uses the conventional nonempty border strip: an edge-connected skew Young diagram with no 2-by-2 square. A single cell satisfies that definition. The proof also applies to the one-cell Young graph and to any edge relation that contains the empty-to-one-cell edge. `connected_for_any_border_relation` formalizes that robustness.

A graph with an additional rule permitting only borders of length `s` or `t` would be a different definition. This project does not claim to refute that modified version. The precise convention and primary reference are stated in `report.tex` and `report.pdf`.

## Reproduce the formal proof

Install/use the official Lean 4.31.0 release through your usual Lean installation, or put its `bin` directory on `PATH`. No Mathlib or other external Lean dependency is needed.

```sh
bash reproduce.sh
```

Invoke the script with `bash` so reproduction also works when a GitHub web upload stores shell scripts without executable permission. The report's `./reproduce.sh` shorthand assumes an executable bit; `bash reproduce.sh` executes the same commands without that requirement.

The script checks Lean and Lake versions, runs `lake build +Basic`, re-elaborates `Basic.lean`, and runs `lake env leanchecker -v Basic`. All steps passed on 2026-10-11 UTC. `leanchecker` replays the authored declarations using Lean's kernel; it is not a separate proof assistant.

Axiom audits for `classify`, `singleton_border`, `component_count_one`, `connected_for_any_border_relation`, and `counterexample` contain only the standard foundational axioms `propext` and `Quot.sound`. There are no unproved declarations, external decision oracles, or kernel overrides.

## Formal statement coverage

`IsPartition` uses positive, weakly decreasing row lengths. `hook` counts the cell and its arm and leg. `IsCore` excludes divisibility by the specified core parameter at every cell. The classification theorem covers arbitrary partition size, not a finite experimental cutoff.

`cells` and `skew` construct the actual finite Young diagrams. `Border` expresses diagram containment, nonemptiness, edge connectivity, and absence of 2-by-2 squares. `Vertex` is the subtype of all genuine simultaneous cores. `Reach` is undirected path equivalence; `Component` is the corresponding quotient. `HasCard` means an explicit bijection with `Fin n`, rather than a hand-chosen component-count function.

The capstone `TLMC3829.counterexample` proves coprimality, component cardinality one, and failure of the claimed cardinality. `binomial_numerator` proves `binom 5 2 = 5 * 2`, so integer division agrees exactly with the rational expression at the witness.
